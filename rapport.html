Labyrinthe avec Tracking de Couleur en Temps Réel

Introduction

Ce projet consiste en un jeu interactif où l'utilisateur doit naviguer dans un labyrinthe en utilisant un objet coloré devant sa webcam. Le système utilise la reconnaissance de couleur en temps réel pour suivre les mouvements de l'objet et les traduire en déplacements dans le jeu.

Technologies Utilisées

OpenCV

Traitement d'image et détection de couleur

SFML

Interface graphique et gestion des événements

C++

Langage de programmation principal

Fonctionnalités Principales

1. Détection de Couleur

Le système utilise l'espace colorimétrique HSV pour une détection robuste des couleurs. L'utilisateur peut sélectionner n'importe quelle couleur en cliquant sur l'objet dans l'image de la caméra. 

void MaskCreation(cv::Mat& frame, cv::Mat& mask, cv::Mat& hsv) {
    cv::cvtColor(frame, hsv, cv::COLOR_BGR2HSV);
    cv::inRange(hsv, Mask1.mini, Mask1.maxi, mask);
}

2. Suivi de Position

L'algorithme Moore-Neighbor Tracing est utilisé pour suivre le contour de l'objet coloré avec une complexité O(P), où P représente le nombre de pixels du contour. Cet algorithme est basé sur cette implémentation qui permet un suivi de contour efficace.

3. Gestion du Jeu

Le jeu propose plusieurs niveaux de labyrinthe avec des difficultés croissantes. Une particularité intéressante est l'utilisation de deux représentations du même labyrinthe : une version PNG affichée via SFML pour le rendu graphique, et une version JPG traitée par OpenCV pour la détection des collisions. Les variables sont partagées entre les différents modules (comme le numéro du labyrinthe actuel) pour assurer la synchronisation entre l'affichage et la logique de jeu.

Le système inclut :

  • Détection de collision avec les murs
  • Zone de départ et d'arrivée
  • Système de score
  • Effets sonores et visuels

Algorithmes Clés

Détection de Collision

La détection de collision utilise une image en niveaux de gris du labyrinthe où les murs sont représentés par des pixels noirs. 

if (lab.image.at(ccy, ccx) < 128) {
    // Collision détectée
    game.touchWall();
}

Interface Utilisateur

L'interface comprend :

  • Affichage en temps réel de la caméra
  • Superposition du labyrinthe
  • Indicateurs de position et de score
  • Boutons de contrôle (Start, Stop, Reset)

Optimisations

  • Utilisation de threads pour le traitement d'image
  • Algorithme optimisé de suivi de contour
  • Gestion efficace de la mémoire avec smart pointers

Programmation Orientée Objet

Ce projet a été l'occasion de plonger dans la programmation orientée objet en C++, un paradigme qui nous a initialement posé quelques difficultés. Nous avons implémenté plusieurs classes clés :

  • GameSession : Gère l'état du jeu et les transitions entre les différentes phases
  • MasqueCouleur : Encapsule les paramètres de détection de couleur
  • Position : Structure simple mais efficace pour la gestion des coordonnées
  • Labyrinthe : Contient les données et méthodes liées au labyrinthe actif

Bien que l'implémentation des classes ait été un défi au début, notamment pour la gestion des membres privés et l'organisation des méthodes, cela nous a permis de mieux structurer notre code et de faciliter la maintenance. C'était une excellente opportunité de mettre en pratique les concepts de la POO dans un projet concret.

Conclusion

Ce projet démontre l'utilisation efficace de la vision par ordinateur pour créer une interface homme-machine interactive. Les choix technologiques (OpenCV, SFML) permettent un traitement en temps réel fluide et une expérience utilisateur agréable.
