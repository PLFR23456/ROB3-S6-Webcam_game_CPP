\doxysubsection{Detailed Description}
Point d\textquotesingle{}entrée principal de l\textquotesingle{}application de suivi de couleur. 

Ce fichier contient la fonction main qui initialise et coordonne les différents composants de l\textquotesingle{}application \+: le traitement vidéo en temps réel et l\textquotesingle{}interface utilisateur graphique.

L\textquotesingle{}application fonctionne avec une architecture multi-\/thread \+:
\begin{DoxyItemize}
\item Thread principal \+: Interface graphique (SFML) et gestion des événements
\item Thread secondaire \+: Traitement vidéo (Open\+CV) et détection de couleur
\end{DoxyItemize}

Thread dédié au traitement de l\textquotesingle{}image

Ce thread exécute la fonction \doxylink{camera_8hpp_a871951369ab5d424568880b98bf3e182}{camera()} qui gère \+:
\begin{DoxyItemize}
\item L\textquotesingle{}acquisition vidéo depuis la webcam
\item La détection de couleur en temps réel
\item Le calcul de position du marqueur coloré
\item La détection des collisions avec les éléments du jeu
\end{DoxyItemize}

Le thread fonctionne en boucle continue jusqu\textquotesingle{}à réception du signal d\textquotesingle{}arrêt stop\+\_\+signal.

Interface graphique principale

La fonction \doxylink{camera_8cpp_a4b0cfcdacc75426e5ed31b9ce093a6b1}{display()} s\textquotesingle{}exécute dans le thread principal et gère \+:
\begin{DoxyItemize}
\item La fenêtre SFML et les événements utilisateur
\item L\textquotesingle{}affichage du flux vidéo traité
\item Le rendu des éléments de jeu (labyrinthes, zones)
\item L\textquotesingle{}interface utilisateur (boutons, score, paramètres)
\end{DoxyItemize}

Cette fonction est bloquante et retourne seulement quand l\textquotesingle{}utilisateur ferme l\textquotesingle{}application.

Attente de la fin du thread de traitement

Avant de terminer le programme, on s\textquotesingle{}assure que le thread de traitement vidéo se termine proprement. Cela évite \+:
\begin{DoxyItemize}
\item Les fuites de ressources (caméra, mémoire)
\item La terminaison brutale du processus
\item Les erreurs de segmentation potentielles
\end{DoxyItemize}
