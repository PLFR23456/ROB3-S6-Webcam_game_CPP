\doxysubsection{Detailed Description}
Classe principale gérant l\textquotesingle{}état et la logique du jeu. 

Cette classe encapsule toute la logique de jeu, incluant \+:
\begin{DoxyItemize}
\item La gestion des états (démarrage, pause, victoire, défaite)
\item Le contrôle de l\textquotesingle{}affichage (page ouverte/fermée, labyrinthe visible)
\item La détection des événements de jeu (collision, zones spéciales) 
\end{DoxyItemize}
