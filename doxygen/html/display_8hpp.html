Gère l'interface graphique SFML, les événements utilisateur, l'affichage de la caméra, du labyrinthe, et des éléments UI

Fonction principale d'affichage et de gestion des événements.

Cette fonction gère l'intégralité de l'interface graphique du jeu, incluant :

  • La création et gestion de la fenêtre SFML
  • L'affichage du flux vidéo de la caméra
  • Le rendu des éléments de jeu (labyrinthes, zones de départ/arrivée)
  • La gestion des boutons et interactions utilisateur
  • L'affichage des messages de statut (victoire, défaite, initialisation)
  • La lecture des sons et animations
Parameters
gameRéférence vers l'objet GameSession qui gère l'état du jeu
Returns
int Code de retour (0 = succès, -1 = erreur de chargement de ressources)

Interface utilisateur :

  • Bouton Start/Stop : Active/désactive le flux caméra
  • Bouton Quit : Ferme l'application
  • Bouton Play/Pause : Lance/met en pause le jeu
  • Zone de sélection de mode : Change le labyrinthe (1-8)
  • Affichage du score en temps réel
  • Sélection de couleur par clic sur l'image

États du jeu gérés :

  • NOT_PLAYING : Jeu en attente
  • INITIALIZING : Phase de préparation (3-4 secondes)
  • PLAYING : Jeu en cours
  • WINNING : Victoire (animation + son)
  • Game Over : Défaite (animation + son aléatoire)

Ressources utilisées :

  • Police : "./extras/DejaVuSans.ttf"
  • Logo : "./extras/logo2.png"
  • Labyrinthes : "./extras/lab[1-4].png"
  • Sons : "./extras/sounds/[1-3].mp3"
  • GIFs : "./extras/win.gif", "./extras/screamgif/00[1-6].gif"
