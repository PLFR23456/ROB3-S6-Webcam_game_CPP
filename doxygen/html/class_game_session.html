Detailed Description

Classe principale gérant l'état et la logique du jeu.

Cette classe encapsule toute la logique de jeu, incluant :

  • La gestion des états (démarrage, pause, victoire, défaite)
  • Le contrôle de l'affichage (page ouverte/fermée, labyrinthe visible)
  • La détection des événements de jeu (collision, zones spéciales)
